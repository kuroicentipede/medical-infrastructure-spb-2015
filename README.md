## Название проекта

Анализ медицинской инфраструктуры Санкт-Петербурга на основе открытых данных (2015)

## Описание

Проект посвящен исследованию медицинской инфраструктуры Санкт-Петербурга на основе открытых государственных данных.

В ходе работы выполнены:

- очистка и преобразование исходных данных;
- проектирование реляционной структуры базы данных;
- загрузка и проверка данных в PostgreSQL;
- SQL-анализ лицензируемых видов медицинской деятельности и медицинских организаций;
- подготовка аналитических материалов.

## Цель

Проанализировать структуру лицензируемой медицинской деятельности Санкт-Петербурга, определить наиболее распространённые виды деятельности, их сочетания и особенности специализации медицинских организаций по данным реестра лицензий за 2015 год.

## Технологии

- PostgreSQL
- SQL
- Microsoft Excel
- Power Query
- Tableau
- Power Point

## Источник данных

Реестр лицензий на осуществление медицинской деятельности, предоставленных Комитетом по здравоохранению (2015).

Источник: https://data.gov.ru/datasets/c7093721-38ae-4ac9-8fa0-bef985982fb4

## Структура базы данных

Основные таблицы:

- `licenses` — медицинские организации и лицензии;
- `lic_addresses` — адреса осуществления лицензируемой деятельности;
- `lic_activ` — связь лицензий с видами медицинской деятельности.

## Аналитика

В рамках проекта исследуются:

- наиболее распространённые и редкие виды медицинской деятельности;
- широта лицензируемого профиля медицинских организаций;
- наиболее частые сочетания видов медицинской деятельности;
- соотношение узкопрофильных и многопрофильных организаций;
- организации, связанные с единичными видами деятельности.
